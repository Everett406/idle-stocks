## 1. 概述

### 1.1 一句话
一款 24 小时持续运转、永远不停歇的虚拟股市，让玩家在碎片时间里做交易、收分红、
升级、转生，从散户成长为传奇经理。

### 1.2 目标平台
- Android `flutter build apk --release`
- 最低 API 21 (Android 5.0)，目标 API 34 (Android 14)
- 仅竖屏单手操作
- 离线可玩：无网络要求

### 1.3 核心循环
```
看行情 → 选股 → 买/卖 → 持仓收分红 → 升级/解锁新股票 → 转生 (周目)
                                ↘ 每日任务 / 限时夜盘
```

## 2. 市场模型 (GBM)

### 2.1 价格演化
每只股票价格按 **几何布朗运动** (GBM) 演化，每 1 秒 tick 一次：

```
S(t+dt) = S(t) * exp((μ - 0.5 * σ²) * dt + σ * sqrt(dt) * Z)
```

其中 `Z ~ N(0, 1)` 由 Box-Muller 方法从 `dart:math.Random()` 生成。

### 2.2 参数换算

- `μ`（每秒漂移）= `dailyDrift / 86400`
- `σ`（每秒波动）= `dailyVol / sqrt(86400)`
- `dt = 1` 秒

### 2.3 事件叠加
事件期间，价格额外乘 `(1 + effect * decay)`，`decay` 从 1 线性衰减到 0（事件结束归 0），
等效于在 GBM 之上叠加临时 boost 倍数。

### 2.4 夜盘激战 (21:00–22:00 本地时间)
- 所有股票 `σ *= 2`
- 所有股票 `dailyDivRate *= 1.5`
- 全局状态由 `GameState` 在 tick 头部按本地小时切换生效区间。

### 2.5 转生加成
经理等级 `L ≥ 0`：
- 分红永久加成 `+15% / 级`（乘法叠加进 `dividendMult`）
- 全市场 `dailyDrift += 5% / 级`（乘法叠加进 `μ`）

## 4. 事件系统

### 4.1 触发节奏
- 每 **90~240 秒** 在已解锁股票中随机选一只触发一次事件
- 单只股票 5 分钟内不会重复触发同向事件（避免刷屏）

### 4.2 幅度与时长
- 幅度：±8%~18%（利好为正、利空为负）
- 持续：3~8 分钟
- 期间价格 `S(t) = S_gbm(t) * (1 + effect * decay)`
- `decay` 从 1 线性衰减到 0

### 4.3 新闻标题模板
利好 10 条 / 利空 10 条，带 `{name}` 占位替换股票名。例：

- 利好：「{name}发布革命性新品，市场沸腾」「{name}斩获超级大单，业绩可期」
- 利空：「{name}陷入财务造假传闻」「{name}核心产品遭监管调查」

完整模板见 `lib/core/constants.dart`。

### 4.4 UI 反馈
- 顶部红色 `BREAKING` 横幅滑入，`HapticFeedback.mediumImpact`
- 利好：金色光晕；利空：蓝/暗色光晕
- 详情页折线图上叠加事件标记 (竖向虚线)

### 4.5 预告
升级 `news_push ≥ 1` 时，事件触发**前 30 秒**在首页顶部弹预告横幅。

## 5. 交易

### 5.1 单位
A股习惯整手简化：1 股起，快捷 `1 / 10 / 100 / 全部`。

### 5.2 手续费
- 基础 `fee = 0.20%`
- 佣金折扣升级 Lv0~5：每级 `-0.03%`，最低 `0.05%`
- 买入：`cash -= shares * price * (1 + fee)`
- 卖出：`cash += shares * price * (1 - fee)`

### 5.3 持仓
- 每只票独立 `Holding { shares, avgCost }`
- 买入时 `avgCost = (oldShares * oldAvg + newShares * price) / (oldShares + newShares)`
- 卖出时 `shares` 减少，`avgCost` 不变
- 校验现金 / 持仓充足

## 6. 分红

### 6.1 在线累加 (每秒)
对每只已解锁且有持仓的股票：
```
pot += shares * price * dailyDivRate / 86400 * dividendMult
```
其中 `dividendMult = 1.0 + upgrade.div * 0.25`（升级每级 +0.25，上限 x3.0），
且受经理等级永久加成：`dividendMult *= 1 + 0.15 * managerLevel`。

### 6.2 结算
每 5 秒一次：把 `dividendPot` 全部加到 `cash`，触发金币粒子 + "+¥xx" 飘字。

### 6.3 离线收益
- 上限 8 小时
- 离线秒数 `T` 内累计分红：
  ```
  total = Σ (shares * savedPrice * dailyDivRate / 86400) * dividendMult
  ```
- 进入应用时若 `lastSave` 距今 > 60 秒，先结算再弹离线收益报告
- 报告逐项累加展示，最后总资产金光闪烁大跳

## 7. 升级系统

| 升级 ID | 名称 | 等级范围 | 每级效果 | 下一级价格公式 |
| - | - | - | - | - |
| `fee` | 佣金折扣 | 0~5 | `fee -= 0.03%`（最低 0.05%） | `cost = 5,000 * 3^level` |
| `div` | 分红倍率 | 0~8 | `dividendMult += 0.25`（上限 x3.0） | `cost = 4,000 * 2.5^level` |
| `bot` | 自动交易机器人 | 0~3 | 阈值 / 单次股数 见 §7.1 | `cost = 25,000 * 4^level` |
| `stop` | 止损保险 | 0~3 | 触发阈值 `8% / 6% / 4%` | `cost = 15,000 * 3^level` |
| `news` | 新闻推送 | 0~1 | 事件预告开启 | `cost = 30,000` |

升级用现金购买；总等级数和价格曲线均偏陡，避免过早 maxed。

### 7.1 自动机器人规则
每 30 秒扫描自选股：
- Lv1：低于持仓均价 95% 且现金够买 10 股 → 买 10 股
- Lv2：低于持仓均价 93% 且现金够买 30 股 → 买 30 股
- Lv3：低于持仓均价 90% 且现金够买 100 股 → 买 100 股
- 同时：高于持仓均价 105% / 107% / 110% → 卖一半

只对自选股生效，UI 在"成长"页可开关单只票的机器人覆盖。

## 8. 每日任务

- 每天本地日期 (`YYYY-MM-DD`) 重置
- 用日期 hash 随机选 3 个任务模板（共 8 个）
- 时长 10 分钟量级，例如：
  - 「完成 2 笔交易」
  - 「今日盈利 ≥ ¥3,000」
  - 「累计分红 ≥ ¥500」
  - 「持有某只今日涨幅 ≥ 2% 的股票」
- 奖励：现金 / 分红加倍卡 (×2 / 10 分钟)
- 跨天未领的进度会重置

## 9. 夜盘激战

- 时间窗口：每天本地 21:00–22:00
- 效果：`σ *= 2`，`dailyDivRate *= 1.5`
- 顶部持续高亮提示卡 (成长页)

## 10. 转生

### 10.1 触发条件
```
totalAssets >= 500,000 * (managerLevel + 1)²
```
- 0 转生：500,000
- 1 转生：2,000,000
- 2 转生：4,500,000
- 3 转生：8,000,000

### 10.2 效果
- 现金重置为 100,000
- 清空所有持仓
- 升级等级全部重置
- 股票重新按解锁阈值锁定
- `managerLevel += 1`
- 永久加成：分红 `+15%/级`、全市场漂移 `+5%/级`
- 播放 prestige 音效 + 全屏金光旋转徽章

### 10.3 UI
成长页有转生卡：进度条到阈值、转生按钮、当前永久加成列表。

## 12. UI / UX 规范

### 12.1 双主题
- 暗色（默认金融终端）：scaffold `#0B1220`、卡片 `#131C2E`、主色金 `#D4AF37`、
  次色青绿 `#2DD4BF`、涨红 `#F04A4A`、跌绿 `#2FBF8F`
- 亮色（白底炒股 App）：scaffold `#F7F8FA`、卡片白、主色证券红 `#D93026`、
  次色 `#0B7A55`、涨红 `#D93026`、跌绿 `#0B7A55`
- 主题切换三态：system / light / dark（持久化）

### 12.2 红涨绿跌
中国习惯：涨红跌绿，无论明暗主题。所有涨跌方向统一不变。

### 12.3 等宽数字
所有金额/价格/涨跌幅 `TextStyle`：
```dart
TextStyle(
  fontFamily: 'monospace',
  fontFeatures: [FontFeature.tabularFigures()],
)
```
使用 Android 系统等宽回退字体，避免不同数字宽度造成的视觉跳动。

### 12.4 单手操作
- 底部 3 Tab，最大点击区
- 详情页买卖大按钮在底部屏幕 70% 高度内
- 任何 destructive 操作（卖出 / 转生）均需二次确认或长按

### 12.5 动画分级原则
- **高频轻量**：价格跳动、迷你走势图、CountUpText（200~400ms）
- **中频常规**：卡片描边呼吸、详情页分时图延伸、ticker tape
- **低频重金**：解锁 overlay、转生 overlay、离线报告 sheet（金光、shake、scale）

避免在低频重金动画里塞高频元素（性能与注意力冲突）。

## 14. 数值节奏目标

| 时段 | 目标 |
| - | - |
| 0–10 min | 玩家完成第一次买入、收一次分红、看到第一个事件 |
| 1 小时 | 解锁第 3 只票、升 2 级升级 |
| 1 天 | 解锁第 6 只票、考虑首次转生 |
| 1 周 | 经理 Lv.2+、解锁全部 10 只票 |

通过每日漂移、分红率与升级价格曲线联合调优，使中位数玩家在合理节奏下推进，
避免"开图 5 分钟就转生"或"两天还卡在第二只票"。

## 15. 版本管理

- `version.txt` 为唯一来源 (`X.Y.Z`)
- CI 校验 tag `vX.Y.Z` 与 `version.txt` 一致，不一致则终止
- 通过 `--build-name=X.Y.Z`、`--build-number=$GITHUB_RUN_NUMBER`、
  `--dart-define=APP_VERSION=X.Y.Z` 注入
- 应用内设置页展示 `APP_VERSION`，便于反馈时定位
