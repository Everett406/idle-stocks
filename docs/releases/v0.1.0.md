# v0.1.0 — 首个 MVP

发布日期：2026-09-17

这是「股海大亨」的首个可玩版本，覆盖核心循环：看行情、买卖、收分红、升级、转生。

## 🎯 玩法亮点

- **10 只虚构股票**——从 XCBK 星辰银行起步，按总资产阈值逐步解锁到 TMGX 天马微芯
- **24/7 永不停歇的虚拟股市**——1 秒 tick，GBM 几何布朗运动驱动
- **随机事件**——利好 / 利空新闻 ±8%~18%，持续 3~8 分钟，红色 BREAKING 横幅
- **自动交易机器人**、**止损保险**、**新闻推送** 三种辅助升级
- **每日任务**——3 个随本地日期种子生成的小目标，奖励现金或 10 分钟分红 ×2 加倍卡
- **夜盘激战**——21:00–22:00 全市场波动翻倍、分红 ×1.5
- **转生系统**——经理等级解锁永久加成 (分红 +15%/级、漂移 +5%/级)

## 🛠️ 技术

- Flutter 3.24.5 / Dart 3.5、Material 3
- 状态：单个 `ChangeNotifier` + 1s / 5s `Timer`
- 存档：`shared_preferences` JSON (key: `save_v1`)，每 10 秒 + 切后台自动保存
- 离线收益：最长 8 小时分红一次性结算，底部 sheet 报告
- 双主题：深色金融终端 / 浅色清爽 App，红涨绿跌（中国习惯），等宽数字
- 音效：audioplayers 5.x，5 个自合成 WAV

## ✅ 已实现

- 底部三 Tab：市场 / 持仓 / 成长
- 顶部无限循环行情条 (ticker tape)
- 股票卡列表 + 迷你走势图 (持仓 / 自选带呼吸描边)
- 详情页分时图 (每秒延伸) + 买卖面板 + 金币粒子 + toast
- 资产总览 (CountUpText) + 今日盈亏
- 升级列表 + 每日任务 + 转生卡
- 离线收益 sheet、金币飘字、解锁 / 转生 overlay、事件 BREAKING 横幅

## ⚠️ 已知限制

- 无单元 / Widget 测试（v0.2.0 起补齐）
- gradle-wrapper.jar 未随仓库提交，CI 首次构建会从 `distributionUrl` 下载
- 仅竖屏
